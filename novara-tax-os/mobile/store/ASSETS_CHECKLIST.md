# App icons & screenshots checklist

## Icons

| Asset | Size | Status |
|-------|------|--------|
| iOS App Store icon | 1024×1024 PNG (no alpha) | Owner design / export needed |
| Android adaptive icon foreground | 512×512+ | Owner design / export needed |
| Android feature graphic | 1024×500 | Owner design / export needed |

Use NOVARA brand colors from the web app (avoid generic purple AI look). Source web fonts: Syne / Figtree.

## Screenshots (minimum)

### iOS

- 6.7" display — TC dashboard, document upload, review/sign  
- 6.1" display — same set  
- iPad (if supporting) — office pipeline  

### Android

- Phone — TC / TP / Office entry  
- 7" tablet optional  

Capture from TestFlight / internal build after `sync:web`. Do not show real taxpayer data — use synthetic demo accounts only.
