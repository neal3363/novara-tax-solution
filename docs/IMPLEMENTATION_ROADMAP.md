# IMPLEMENTATION_ROADMAP.md

Preserves Blueprint v1.2/v1.3 phases and inserts Version 1.4 competitive expansions without replacing legal/security gates.

## Phase A — Working preview ✅
1. Design system + public site
2. Four portal shells
3. Executive discovery dashboard + national map
4. Synthetic data + workflow visibility
5. Foundation automated tests
6. Documentation set

## Phase B — Auth, audit, and policy hardening ✅ (preview-complete)
- Preview session cookies + middleware portal isolation
- Simulated MFA gate on portal routes
- Immutable audit store (append-only API)
- ABAC attributes (territory, opportunity lock, sensitivity)
- Partner circumvention controls (export watermarking + audit)
- Competitive expansions surfaced in product UI: enrichment, bulk ops, genealogy, claim prep, provider comparison, international routing

## Phase C — Legal / compensation / source-rights engines (next)
- Legal memorandum schema + rule publishing
- Transaction-specific compensation models
- Data Rights Records + connector permission classes
- Kill switches

## Phase D — Continuous discovery pipeline
- Source schedule registry
- Change detection + durable event bus
- Delta workers, dedupe, reconciliation, freshness service
- Texas deep pilot before national scale

## Phase E — Domain intelligence modules
- Unclaimed, estate/heir, property, bankruptcy/court/federal, minerals, business
- Competitive expansions 1–10 matured behind rights gates

## Phase F — Network, finance, assurance
- 100-partner network operations
- Segregated ledgers and payouts
- Guardian production monitoring
- SOC 2 / DR / pen test readiness

## Definition of done (unchanged)
A state/asset workflow is not production-live until memo, rule version, compensation model, data rights, security review, attorney coverage, isolation tests, audit trail, and sign-off are complete.
