# COMPETITOR_GAP_ANALYSIS.md

Publicly documented capabilities were benchmarked for **inspiration only**. No proprietary designs or code were copied.

## Competitor snapshots

### Tracers (~50% UI/UX influence)

- Investigative search and entity-oriented research
- People/asset pointer intelligence for investigators and counsel
- Batch research patterns and dense record presentation

### Claimiflo (~30% workflow influence)

- Multi-jurisdiction unclaimed property monitoring
- Claim tracking tickets and document vault
- Bulk review patterns and executive reporting
- Explicit non-guarantee / claimant-of-record posture (useful compliance tone)

### HeirSearch (~20% credibility influence)

- Forensic genealogy research process
- Court-suitable written reports with supporting documentation
- Professional researcher assignment model
- Property / heir / unclaimed holder search services
